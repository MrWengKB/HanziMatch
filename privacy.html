“拼音配对”隐私政策

生效日期：2026 年 11 月 27 日

安卓 App

“拼音配对”安卓 App（包名 io.github.mrwengkb.hanzimatch）不收集、不存储、不分享任何个人信息。App 没有账号系统，没有广告，也不包含任何统计或分析工具。

  • 本地保存的设置：你选择的年级、课次、字数和游戏模式只保存在你自己的设备上，不会上传。
  • 检查更新：App 会向 GitHub（api.github.com）查询最新版本号。如果你选择安装更新，会从 GitHub 下载安装包。这些请求不包含任何个人信息；GitHub 作为网络服务商可能会按其隐私声明记录访问日志（例如 IP 地址）。
  • 安装权限：“安装未知应用”权限只用于安装你主动选择的更新。

网页版

网页版（mrwengkb.github.io/HanziMatch）使用 Google Analytics 统计匿名的访问情况（如页面浏览次数、设备类型），用于了解使用情况。详见 Google 隐私政策。安卓 App 中不包含这部分。

儿童隐私

本游戏面向小学生学习汉字拼音。我们不会有意收集任何儿童的个人信息。

Privacy Policy – Pinyin Match

Effective: November 27, 2026

The Android app (io.github.mrwengkb.hanzimatch) does not collect, store or share any personal data. It has no accounts, no ads and no analytics. Game settings are stored only on your device. To check for updates, the app requests the latest version number from GitHub (api.github.com) and, if you choose to install, downloads the update from GitHub; no personal data is sent, though GitHub may keep standard server logs (such as IP addresses) under its own privacy statement. The "install unknown apps" permission is used only to install updates you choose.

The web version uses Google Analytics for anonymous usage statistics; the Android app does not.

The game is designed for primary-school children. We do not knowingly collect personal information from children. Contact: GitHub Issues.
